## Release Notes

KRISHAN TOOLBOX V3.0 is a stable Termux utility manager release
focused on modular tool management, learning modules, catalog
validation, system checks, favorites, updates, and configuration
backup/restore.

Generated backup archives and cache data are kept local and are not
tracked by Git.
